## 🔭 Overview

**PHANTOM** is a self-contained control-center dashboard that models the
workflow of a professional phishing / social-engineering toolkit across
16 modules in 7 operational categories.

- ✅ **Zero dependencies** — no CDN, no build step, no internet needed
- ✅ **Single file** — everything (HTML/CSS/JS) lives in `phantom.html`
- ✅ **Interactive** — click modules to inspect parameters and execute them
- ✅ **Runs offline** — works from a USB stick, air-gapped machine, or local disk

> ⚠️ This is a **simulation/demo dashboard**. It does not perform real
> attacks. It is intended for training, demonstration, and mock-ups.
